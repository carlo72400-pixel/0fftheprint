Install it

MAC
Unzip it, double-click VPDeadeye-Regular.otf, then click Install.
WINDOWS
Unzip it, right-click VPDeadeye-Regular.otf, then Install.
IPAD / IPHONE
Tap the zip in Files to open it. In Procreate: add text, tap Aa, then Import Font and pick the .ttf.
ANYTHING ELSE
Canva, CapCut, Photoshop: install it on your computer, or upload the .ttf with the app's own upload a font button.
